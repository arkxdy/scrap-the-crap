# Scrap the Crap

An AI-powered knowledge and exam intelligence platform that brings document intelligence and exam preparation into one unified workspace.

### Features
- **Document Intelligence:** Upload, search, summarize, and chat with documents using AI.
- **Exam Intelligence:** Explore historical questions, analyze trends, and generate practice questions.
- **AI Workspace:** Ask questions across documents and exam knowledge with contextual, source-backed answers.

### Tech Stack
- React + TypeScript + Vite
- Tailwind CSS v4 + shadcn/ui
- Python + FastAPI
- PostgreSQL + pgvector
- Ollama for local LLM inference
